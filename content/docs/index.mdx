Marble UI is a set of React components built on [Base UI](https://base-ui.com) and styled with Tailwind CSS. It ships as a [shadcn](https://ui.shadcn.com) registry, so components land in your project as source you can read and change, not a package you work around.

## The material

Everything is cut from the same few materials, so any combination looks like it belongs together.

## How it's organised

- **Theme**: every token, material and motion curve, merged into your `globals.css` when you add it.
- **Components**: one file each under `components/ui`, built on Base UI primitives.
- **Accent**: a single verde accent; everything else is stone.

Start with [Installation](/docs/installation), or browse the components in the sidebar.
